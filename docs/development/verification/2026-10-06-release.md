# 2026-10-06 1.1.2 빌드·패키지 확인

macOS 27(26A428)에서 드러난 출력 장치·커버 이미지·Head Tracking 문제와 AUSpatialMixer 변화에 대응해 `1.1.2`로 올렸습니다.
이 문서는 로컬 산출물의 확인 범위입니다. 다른 Mac의 설치·업그레이드나 macOS 26 실기기 검증은 포함하지 않습니다.

## 버전

| 대상 | 값 |
|---|---|
| `build/Roomcut.app` | 1.1.2 |
| `build/driver/RoomcutHAL/Roomcut.driver` | 1.1.2 |
| 앱 내장 드라이버 | 1.1.2 |
| CMake 프로젝트 | 1.1.2 |
| 배포 대상(minos) | 26.0 — 앱·Now Playing 헬퍼·엔진·`roomcutctl`·`roomcut-devicectl`·드라이버 전부 |

## 1.1.1에서 달라진 것

| 항목 | 내용 | 기록 |
|---|---|---|
| 출력 장치 | 고른 장치를 별도 스레드에서 무음으로 먼저 돌려 보고(`OutputProbe`) 통과해야 전환. 시작이 안 되는 장치는 라우팅에서 빠지고(`OutputQuarantine`) 메뉴에 "재생 불가". 이름 없는 장치는 제조사·연결 방식으로 표시. 실측: 이름 없는 DisplayPort 장치가 시작에서 10 s 멈춘 뒤 `'stop'`, 엔진 제어 스레드가 막혀 "연결 끊김" | 이번 문서 |
| Now Playing 커버 | 512 KB를 넘는 표지는 헬퍼에서 640 px JPEG(투명이면 PNG)로 재인코딩. 실측: Safari(macOS 27)가 무압축 TIFF를 넘겨 한 줄 12,157,454 B → 앱 1 MiB 상한에서 버려짐. 재인코딩 후 61,798 B | 이번 문서 |
| AUSpatialMixer 보정 | 확산음장을 실행 중인 시스템·엔진 프로세스에서 측정(빌드·레이트·HRTF별 캐시). 26과 27이 같은 컴포넌트 버전(`0x00010608`)인데 응답이 최대 4.4 dB 달라 고정 테이블로는 구분 불가 | 이번 문서 |
| Head Tracking | 1초 무샘플이면 엔진을 일반 재생으로 돌리고 센서 재시작(0/1/2/4/8 s 간격), 센서 오류도 재시도, 폴링마다 허용 여부 재계산. 실측: 오류·해제 알림 없이 샘플이 멈추고 재실행 전까지 복구되지 않음 | 이번 문서 |
| 상태 메시지 | STATE 응답 끝에 재생 불가 장치 목록과 확인 중인 장치 추가. IPC 버전 유지, 구 엔진 길이(272 B)를 legacy로 등록, 구 앱 수신 버퍼(1480 B) 안 | 이번 문서 |
| 빌드 | `CMAKE_OSX_DEPLOYMENT_TARGET 26.0` 고정, 헬퍼 `-mmacosx-version-min=26.0`. 지정하지 않으면 macOS 27에서 만든 바이너리가 26에서 실행되지 않음 | 이번 문서 |

## 검사

- 클린 빌드(`rm -rf build`) 후 네이티브 CTest 58/58, Swift XCTest 307/307 통과.
- macOS 26.5 SDK(배포 대상 26.0, `-Werror=unguarded-availability(-new)`)로 엔진·드라이버·테스트·앱·헬퍼 빌드 오류 0, CTest 58/58.
- 배포 바이너리 6개의 시스템 import를 26.5 SDK 스텁(재수출 포함)과 대조: 없는 심볼 0(엔진의 내부 weak 정의 2건 제외).
- `pkgutil --expand-full` 결과: 앱·HAL 드라이버·앱 내장 드라이버가 모두 1.1.2이고 `codesign --verify --strict` 통과. 엔진·`roomcutctl`·`roomcut-devicectl` 서명 통과, 빌드 산출물과 바이트 동일.
- 페이로드: `/Applications/Roomcut.app`, `/Library/Audio/Plug-Ins/HAL/Roomcut.driver`, 엔진·`roomcutctl`·`roomcut-devicectl`, LaunchDaemon plist, `uninstall.sh`, `LICENSE`, `THIRD_PARTY_NOTICES.md`. `preinstall`·`postinstall` 포함.
- 설치 화면 자료: `Distribution`에 readme·license, 최소 macOS 26.0, arm64.
- dmg: `Roomcut-1.1.2.pkg`(dist와 바이트 동일), `Read Me.txt`, `LICENSE.txt`·`THIRD_PARTY_NOTICES.md`(저장소 파일과 동일).
- 이 Mac(macOS 27)에 설치한 엔진: 가짜 장치 선택 중 0.25 s 간격 35회 상태 질의 무응답 0, AirPods 재생 유지, underrun 0. 확산음장을 개인화 HRTF로 측정해 4밴드 보정 적용.

## 한계

- ad-hoc 서명이며 Developer ID 서명·공증은 하지 않았습니다.
- macOS 26·26.5는 SDK 빌드와 심볼 대조로만 확인했고 실기기에서 돌려 보지 않았습니다.
- pkg를 이 Mac에 실제로 설치해 보지는 않았습니다(개발용 엔진·sudoers 설정을 지우기 때문).
- Head Tracking 복구는 단위 테스트와 진단 로그 분석으로 확인했고, AirPods 실사용 재현은 하지 않았습니다. 헤드폰 서라운드의 측정 보정은 청취 평가를 하지 않았습니다.
- `hdiutil create`/`attach`가 macOS 27에서 사용 중단 예고 경고를 냅니다(동작은 정상).
