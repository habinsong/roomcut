# 2026-09-10 1.1.0 빌드·패키지 확인

`1.0.9` 이후 호스트에서 할 수 있는 계획 항목을 끝내고 `1.1.0`으로 올렸습니다.
이 문서는 로컬 산출물의 확인 범위입니다. 다른 Mac의 설치·업그레이드나 실기기 검증은
포함하지 않습니다.

## 버전

앱·드라이버·CMake 모두 `1.1.0`입니다. 빌드한 번들에서 직접 확인했습니다.

| 대상 | 값 |
|---|---|
| `build/Roomcut.app` | 1.1.0 |
| `build/driver/RoomcutHAL/Roomcut.driver` | 1.1.0 |
| CMake 프로젝트 | 1.1.0 |

## 검사

- 네이티브 CTest 43/43 통과 (1.0.9 시점 37개에서 6개 증가).
- Swift XCTest 257/257 통과 (1.0.9 시점 213개에서 44개 증가).
- 드라이버 번들 서명: `codesign --verify --strict` 통과. 앱 번들도 통과.
- 패키지 전개 후 페이로드의 드라이버·앱 서명을 다시 확인했습니다.
- 앱에 동봉한 드라이버는 `Contents/PlugIns`에 두어 `codesign --verify --strict`가 nested code로 검증합니다.
- `pkgutil --expand` 결과에 `preinstall`·`postinstall`이 모두 있고, 페이로드의 시스템 드라이버·앱·앱 내부 드라이버가 모두 1.1.0입니다.

## 한계

- ad-hoc 서명이며 Developer ID 서명·공증은 하지 않았습니다.
- 다른 Mac에서의 신규 설치·업그레이드·제거 후 복구는 확인하지 않았습니다. preinstall의 구버전 제거는 스크립트 내용과 pkg 수록만 확인했고 실제 업그레이드 설치로는 돌려보지 않았습니다.
- 설정 화면의 「드라이버 재설치」·「Roomcut 제거」 버튼은 조합되는 셸 명령의 문법과 osascript 인용만 확인했고, 실제로 실행해 보지는 않았습니다.
- 실제 마이크 측정, 장치 분리·절전·재연결, 청취 평가는 여전히 남아 있습니다(HW-01, RT-01).
- 설치된 엔진을 1.1.0으로 교체한 뒤의 실기기 동작은 이 문서 범위 밖입니다.
