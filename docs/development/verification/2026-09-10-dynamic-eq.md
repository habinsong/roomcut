# 2026-09-10 선택적 다이내믹 EQ (EQ-01)

계획의 7번 항목을 구현했습니다. 파라메트릭 밴드마다 선택적으로 다이내믹 동작을 켤 수
있고, 끄면 기존 정적 밴드와 완전히 같습니다. 실기기 청취 평가는 하지 않았습니다.

## 동작

밴드 주파수·Q에 맞춘 0dB 피크 대역통과 필터로 그 밴드의 RMS를 재고, 임계값을 넘은
만큼을 밴드 게인에서 뺍니다. 최대 감쇠량은 범위(range)로 제한합니다. 어택/릴리스는
레벨이 아니라 감쇠량의 이동 속도를 정합니다. 레벨 평균 창은 밴드 2주기(최소 10ms)로
고정해, 정상 상태 판독값이 어택 설정에 따라 달라지지 않게 했습니다.

검출은 채널 간 연동입니다. 두 채널 중 큰 쪽으로 감쇠량을 정하고 양쪽에 같은 값을
적용하므로 좌우 이미지가 움직이지 않습니다. 계수 반영은 32프레임마다 하며, 블록이
아니라 프레임 수로 세기 때문에 호출자의 블록 크기가 결과를 바꾸지 않습니다.

## 검사

`ctest -R dynamic_eq` 9개 검사입니다.

| 검사 | 확인한 것 |
|---|---|
| 정적 경로 동일성 | 다이내믹을 쓰지 않으면 `processFrame`과 기존 `processSample`의 출력이 비트 단위로 같음 |
| 임계값 아래 | -45dBFS 입력에서 감쇠 0, 출력 변화 0.05dB 이내 |
| 임계값 초과 | -18dBFS 사인(대역 RMS -21dBFS), 임계값 -24 → 감쇠 3.01dB, 출력 -3.01dB |
| 범위 제한 | 임계값을 21dB 넘겨도 범위 4dB에서 멈춤 |
| 어택·릴리스 | 어택 20ms에서 5ms 시점은 목표의 80% 미만, 유지하면 범위까지 도달, 무음 500ms에 3dB 이상 회복, 3초 뒤 0 |
| 채널 연동 | 좌 -6dBFS·우 -40dBFS에서 양 채널 감쇠 차 0.05dB 이내 |
| 블록 크기 | 64프레임과 512프레임 출력이 샘플 단위로 동일 |
| 샘플레이트 | 44.1/48/96/192kHz에서 감쇠 9.01dB ±0.2 |
| 안정성 | 버스트·파라미터 변경·비활성화를 섞어 96000프레임 처리, NaN 없음, 피크 1.5 미만 |

## 비용

`scripts/benchmark-dsp.cpp`에 다이내믹 밴드 수 인자와 렌더 중 힙 할당 카운터를
추가했습니다. 전체 효과·512프레임 기준입니다.

| 조건 | 프레임당 | p99 | 렌더 할당 |
|---|---:|---:|---:|
| 48kHz, 조작 없음, 다이내믹 0 | 134.2ns | 83.4us | 0 |
| 48kHz, 5ms 조작, 다이내믹 0 | 243.4ns | 154.4us | 0 |
| 48kHz, 5ms 조작, 다이내믹 6 | 336.8ns | 207.9us | 0 |
| 384kHz, 5ms 조작, 다이내믹 6 | 343.5ns | 210.0us | 0 |

끈 상태 비용은 이전 측정(48kHz 135.6ns, 384kHz 140.9ns)과 같거나 조금 낮고, 벤치마크
체크섬도 동일합니다. 밴드 6개를 모두 켜면 프레임당 약 +52ns(정지 상태 기준)입니다.
384kHz·512프레임의 블록 주기는 1333us이므로 위 최악 조건도 주기의 16%입니다.

## 전달 경로

- 와이어: `RoomcutParamDynamics` 배열을 기존 밴드 배열 뒤에 덧붙였습니다. 밴드 배치는
  그대로이고, 짧은 구버전 메시지는 0으로 채워져 정적 밴드로 읽힙니다. 수신 크기 목록에
  이전 길이를 추가했습니다. 비교(A/B) 페이로드에도 같은 배열이 들어가며 버전이 2가 됐습니다.
- 능력: `ROOMCUT_CAP_DYNAMIC_EQ`(0x40)를 엔진이 알립니다. 앱은 이 값이 없으면 UI를
  숨기고, 보내는 파라미터에서도 다이내믹을 꺼서 밴드가 기술하는 정적 필터를 보냅니다.
- 상태 파일: `dynamics=` 줄을 추가했습니다. 다이내믹 밴드가 없으면 줄 자체를 쓰지 않으므로
  이전 파일과 같고, 줄이 없으면 전부 정적으로 복원됩니다.
- 프리셋 JSON: 정적 밴드는 새 키를 쓰지 않습니다. 이전 프리셋은 정적으로 디코딩됩니다.
- UI: 밴드 카드를 펼치면 벨/셸프에서만 다이내믹 스위치와 임계값·범위·어택·릴리스가 보이고,
  접힌 카드에는 `DYN` 표시가 붙습니다.

## 한계

  청취나 측정으로 최적값을 정한 것이 아닙니다.
- 밴드가 올라가는 방향(임계값 아래에서 부스트)은 구현하지 않았습니다. 현재는 내려가는
  방향만 있습니다.
