# 2026-09-17 1.1.1 빌드·패키지 확인

`1.1.0` 이후의 Space 기능(가상 서라운드·헤드 트래킹·가상 룸·공간 프리셋)을 담아 `1.1.1`로 올렸습니다.
이 문서는 로컬 산출물의 확인 범위입니다. 다른 Mac의 설치·업그레이드나 실기기 검증은 포함하지 않습니다.

## 검사

- 네이티브 CTest 57/57 통과(릴리스 빌드 디렉터리).
- Swift XCTest 300/300 통과(2026-09-18 교체 자산과 같은 소스).
- `pkgutil --expand-full` 결과: 앱·HAL 드라이버·앱 내장 드라이버가 모두 1.1.1이고 `codesign --verify --strict` 통과. 엔진 바이너리 서명 통과.
- 페이로드: `/Applications/Roomcut.app`, `/Library/Audio/Plug-Ins/HAL/Roomcut.driver`, 엔진·`roomcutctl`·`roomcut-devicectl`, LaunchDaemon plist, `uninstall.sh`, `LICENSE`, `THIRD_PARTY_NOTICES.md`. `preinstall`·`postinstall` 포함, 재배치 없음.

- dmg: `Roomcut-1.1.1.pkg`(dist와 바이트 동일), `Read Me.txt`, `LICENSE.txt`, `THIRD_PARTY_NOTICES.md`(저장소 파일과 동일).
