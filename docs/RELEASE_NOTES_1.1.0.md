## English

Each bell or shelf band in the parametric EQ can now be told to come down only when that band gets loud, Space, Center and Damping reach twice as far on the same 0–100 dial, and Inspect reports the latency Roomcut itself adds separately from the device's. Settings is now a single list, ending with **Reinstall Driver** and **Remove Roomcut** — and the installer clears out any older Roomcut app and driver before laying down this one, which also closes the 1.0.9 bug where the driver's signature no longer covered its own `Info.plist` and **Roomcut Output** never appeared. Install from `Roomcut-1.1.0.pkg` or from `Roomcut-1.1.0.dmg`, which holds the same package; the build is not notarized, so if macOS blocks it, open it once and then choose **System Settings → Privacy & Security → Open Anyway** (Apple Silicon, macOS 26 Tahoe or later).

## Deutsch

Jedes Bell- oder Shelf-Band im parametrischen EQ lässt sich so einstellen, dass es nur absenkt, wenn dieses Band laut wird, Space, Center und Damping reichen auf derselben Skala 0–100 doppelt so weit, und Inspect zeigt die Latenz, die Roomcut selbst hinzufügt, getrennt von der des Geräts. Die Einstellungen stehen jetzt in einer einzigen Liste, die mit **Neu installieren** und **Roomcut entfernen** endet, und das Installationsprogramm entfernt eine ältere Roomcut-App samt Treiber, bevor es diese Version ablegt — womit auch der Fehler aus 1.0.9 erledigt ist, bei dem die Treibersignatur die eigene `Info.plist` nicht mehr abdeckte und **Roomcut Output** nie auftauchte. Installieren Sie über `Roomcut-1.1.0.pkg` oder über `Roomcut-1.1.0.dmg` mit demselben Paket; die Builds sind nicht notarisiert — blockiert macOS sie, einmal öffnen und dann **Systemeinstellungen → Datenschutz & Sicherheit → Trotzdem öffnen** wählen (Apple Silicon, macOS 26 Tahoe oder neuer).
